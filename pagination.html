Sección: Paginación

Esta sección proporciona navegación entre páginas de resultados de forma intuitiva.

Características:

  • Controles de navegación anterior/siguiente con iconos Material Design
  • Indicador visual de la página actual (color teal)
  • Estados deshabilitados para límites de navegación
  • Efecto wave en botones interactivos
  • Centrado para mejor presentación
  • Responsive y accesible

Tipos de navegación:

  • Formato compacto: "Página X / Total" - ideal para catálogos largos
  • Formato extendido: Páginas numeradas individuales - ideal para pocos resultados
